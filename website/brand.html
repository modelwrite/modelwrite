Modelwrite — brand exploration

Four directions, side by side, each applied to the same three artefacts — a hero block, a card row, and a diagram fragment. Each mark is drawn at 16, 32 and 120 px. Palettes and font stacks are printed so the choice is concrete. Self-contained: no external requests, system fonts and inline SVG only. The name stays modelwrite.
