# mw-cli

The `mw` command line: reach a modelwrite service over plain HTTP, or open a SQLite store directly for offline use with commit, merge, gate, lock and audit. Part of the [modelwrite](https://github.com/modelwrite/modelwrite) platform (AGPL-3.0-or-later).

Install with `cargo install --path cli` from the repository (or `cargo install mw-cli` once published), then run `mw --help`.
